# The Dlúth mark

The mark is a woven tile: two vertical loops (the warp, which is what *dlúth* means in weaving) and two
horizontal loops (the weft), each thread passing over and under in turn. It is drawn with the same pen as
the mark of [Meitheal](https://github.com/defilantech/meitheal), its sibling project, and is square where
that one is round.

| File | Use |
|---|---|
| `dluth-logo-light.svg`, `dluth-logo-dark.svg` | The mark with the name, for light and dark backgrounds |
| `dluth-mark.svg`, `dluth-mark-dark.svg` | The mark alone, for light and dark backgrounds. Its edge and gaps are finer than a pixel below about 80 pixels; use the favicon there |
| `dluth-mark-mono-ink.svg`, `dluth-mark-mono-vellum.svg` | The mark in one colour |
| `dluth-favicon.svg` | The mark for small sizes: copper only, no edge, heavier threads that fall on whole pixels at 32 |
| `dluth-social.svg`, `dluth-social-dark.svg` and their `.png` renders | A 1280 by 640 card |

| Colour | Value | Use |
|---|---|---|
| Copper | `#B8693D` | The mark on light backgrounds |
| Copper, dark mode | `#D98A5B` | The mark, the name and the rule on dark backgrounds |
| Ink | `#1E2A24` | The edge of the full mark, the name on light backgrounds |
| Vellum | `#F3EBDD` | Background of the social card; the other files are transparent |
| Soft ink | `#4A5A52` | Small text on vellum |
| Soft vellum | `#C9C0B0` | Small text on ink |

The name is set in Uncial Antiqua (SIL Open Font License 1.1) and stored as outlines, so no font is needed
to show it. The rule under the name spells D L U T H in Ogham, which has no mark for the length of a vowel and so no accent.
The line on the social card is live text in Helvetica Neue, falling back to Arial.
